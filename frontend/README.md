# BreatheIQ Frontend

React 19 + Vite + TypeScript application providing:
- Atmospheric Precision Design System based on Google Stitch designs
- 93 route architecture with lazy loading and role guards
- Interactive CPCB AQI gauges, diurnal charts (Recharts), geospatial station explorer (Leaflet + OSM)
- Multi-language support (English, Hindi, Marathi via i18next)
- BreatheIQ Copilot conversation interface with evidence chips and voice input
